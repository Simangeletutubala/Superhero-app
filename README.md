### Superhero App

A beginner web development project completed during my bootcamp to practise creating an interactive website using HTML and CSS.

The project features a collection of superhero profiles, with character images and information presented in a simple, user-friendly layout. It helped me develop my skills in structuring web pages, styling content, and creating navigation between pages.

**Technologies:** HTML5, CSS3
